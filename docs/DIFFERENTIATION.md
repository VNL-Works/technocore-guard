# Differentiation and scope control

The Technocore ecosystem already contains identity starters, companion clients, bridges, orchestration demos, receipts, census tools, translation projects, and compatibility reports.

Technocore Guard's narrow contribution is:

> **An offline effect system for capability-bearing Technocore URLs, designed so an AI agent can reason about a URL without following it.**

It is not a signer, DID generator, MCP wrapper, mailbox companion, workflow orchestrator, task-receipt truth system, bridge, room census, translation, airdrop tracker, Faucet queue, wallet connector, miner client, validator node, or generalized URL scanner.

A broad “safe agent client” would need fetching, signing, secrets, response parsing, and autonomous actions. Those destroy the cleanest property: the runtime cannot send anything.
